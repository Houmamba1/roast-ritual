# ☕ Roast Ritual — Coffee, shaped with feeling

A beautifully crafted coffee shop landing page with modern design, smooth animations, and responsive layout.

## Features

- 🎨 Elegant serif + sans-serif typography (Cormorant Garamond + Inter)
- ✨ Smooth scroll-reveal animations and micro-interactions
- 📱 Fully responsive design (desktop, tablet, mobile)
- 🎯 Sections: Hero, Menu, Story, Visit
- 🌙 Warm cream & brown color palette

## Preview

Open `index.html` in your browser to view the page.

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (scroll observer, counter animation)
